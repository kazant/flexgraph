Getting started

1. Subscribe, then get your npm token in the customer portal and add an .npmrc to your project:

@flexgraph-labs:registry=https://npm.flexgraph.example/
//npm.flexgraph.example/:_authToken=${FLEXGRAPH_NPM_TOKEN}

2. Install and render:

npm install @flexgraph-labs/flexgraph
import { createGraph, setLicenseKey } from "@flexgraph-labs/flexgraph";
import "@flexgraph-labs/flexgraph/style.css";

setLicenseKey("FG-PRJ-XXXX-XXXX-XXXX-XXXX");
const view = createGraph(document.getElementById("graph"), data, { direction: "LR" });

3. Register your production domain (and up to 3 staging domains) for the project in the portal. On localhost everything works without a key.

Want to try first? npm install @flexgraph-labs/flexgraph-trial — full features on localhost with a watermark.

Saving a layout

Users can drag nodes until the lines run the way they want. exportState() returns plain JSON with the node positions, pins, zoom and the exact edge lines. Store it anywhere (your database, localStorage, a file) and pass it to importState() to recreate the same picture. If a node has changed size since it was saved (other fonts, edited labels), the lines on that node are routed fresh instead.

// save
const state = view.exportState();
await fetch("/api/diagrams/42/layout", { method: "PUT", body: JSON.stringify(state) });

// restore
const view = createGraph(el, data);
await view.ready;
await view.importState(await (await fetch("/api/diagrams/42/layout")).json());

// or autosave after every drag
view.on("change", (state) => save(state));

What happens if a payment fails?

Your graphs keep working for 14 days and we email you on day 1, 7 and 13. After that, graphs on your site show a “License inactive” overlay to your users until the payment goes through. A canceled subscription keeps working until the end of the paid period.

Open-source and non-commercial projects: ask us about a free license.

Content Security Policy

The library validates its license against https://license.flexgraph.example. If your site uses a CSP, allow it in connect-src:

Content-Security-Policy: connect-src 'self' https://license.flexgraph.example

Validation happens about once a week per browser (the signed token is cached). If the license server is unreachable, the graph keeps working.

Offline / intranet projects

With the offline add-on, the portal issues a signed key bound to your domain (FG-OFF-…). It needs no network access and is valid for the paid period + 14 days. A new key is emailed every month — update it in your project:

setLicenseKey(process.env.FLEXGRAPH_OFFLINE_KEY);

How it's built

FlexGraph is written from scratch in plain JavaScript (ES modules, ES2020). It is not a fork or wrapper of Dagre, ELK or any other library.

Dependencies

PackageUsed forShipped to your users?
NoneRuntime: the library imports nothing—
esbuildBuilding the minified bundles (dev dependency)No
dagreOnly for the quality comparison script (npm run compare)No

Bundle size: about 79 kB minified (about 30 kB gzipped) for the main ESM file, plus an optional 38 kB Web Worker file. ESM and UMD builds, TypeScript definitions and a default stylesheet are included.

Techniques

  • Layout: a Sugiyama-style layered layout. Cycles are broken by reversing DFS back edges, layers come from longest-path ranking with compaction, and crossings are minimized with barycenter and median sweeps (the approach used by Graphviz dot), transposition and sifting, from several starting orders.
  • Node positions: weighted isotonic regression per layer (pool-adjacent-violators), which keeps long edges straight and respects pinned nodes.
  • Edge routing: A* search on a sparse orthogonal grid around the nodes, with penalties for bends and crossings; parallel segments are spread onto separate tracks, with line hops where lines must cross.
  • Groups and constraints: compound layout so group boxes never overlap; pinned, same-rank, fixed-rank and left-of constraints.

Browser features used

SVG for edges and markers, HTML elements for nodes, CSS custom properties for theming, Pointer Events for drag, pan and pinch, requestAnimationFrame for animation, and optionally a Web Worker for large graphs. The layout engine itself uses no DOM, so it also runs in Node.js and in workers.

License verification uses fetch, Web Crypto (ECDSA P-256 signatures, with a pure-JS fallback on plain http pages) and localStorage to cache the signed token. The license server runs on Cloudflare Workers with D1 (database) and R2 (package storage).

Development needs Node.js 20 or newer; tests use the built-in node --test runner.

FAQ

What counts as a project?

One application: one production domain plus up to three non-production domains. Three applications need three licenses.

What data does the license check send?

The license key, the hostname and the library version. Nothing about your users. See the privacy policy.

Can I use it with React / Vue / Svelte / Angular?

Yes. FlexGraph has no framework dependencies: create the graph when the component is mounted and call view.destroy() when it is removed. In React that is a useEffect, in Vue onMounted / onUnmounted, in Svelte onMount.

How do I use it in Angular?

FlexGraph works with zoneless Angular (the default in new projects): create the graph once the element has rendered, update it from an effect when the input changes, and destroy it with the component. Click callbacks can set signals directly; that is enough to update the view. Add the stylesheet to "styles" in angular.json: "node_modules/@flexgraph-labs/flexgraph/style.css".

import { Component, ElementRef, DestroyRef, afterNextRender, effect, inject, input, signal, viewChild } from "@angular/core";
import { createGraph, type GraphData, type GraphView } from "@flexgraph-labs/flexgraph";

@Component({
  selector: "app-graph",
  template: `
    <div #host style="height: 600px"></div>
    @if (selected(); as s) { <p>Selected: {{ s }}</p> }
  `
})
export class GraphComponent {
  data = input.required<GraphData>();
  host = viewChild.required<ElementRef<HTMLDivElement>>("host");
  selected = signal<string | null>(null);
  private view?: GraphView;

  constructor() {
    afterNextRender(() => {
      this.view = createGraph(this.host().nativeElement, this.data(), {
        direction: "LR",
        onNodeClick: (node) => this.selected.set(node.label ?? node.id)   // a signal update re-renders
      });
    });
    effect(() => {
      const data = this.data();
      this.view?.updateGraph(data);   // existing nodes stay in place
    });
    inject(DestroyRef).onDestroy(() => this.view?.destroy());
  }
}

Still on zone.js? The same component works; optionally create the graph inside NgZone.runOutsideAngular so dragging and zooming don't trigger change detection. For very large graphs, copy flexgraph.worker.js to your assets and pass its URL as the worker option.
